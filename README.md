## 🚀 Funcionalidades Principais

- 🎡 **Roleta Interativa da Feira (`js/wheel.js`)**: Mecânica de sorteio interativa com física de rotação e prêmios do estande.
- ♻️ **EcoSort Game (`js/ecosort.js`)**: Minigame dinâmico de coleta e separação correta de resíduos para reciclagem.
- 🧠 **Quiz Interativo (`js/quiz.js`)**: Perguntas dinâmicas sobre sustentabilidade, energia limpa e engenharia ambiental.
- 📊 **Simulador de Impacto (`js/simulator.js`)**: Calculadora e simulador visual de redução de pegada de carbono e economia de recursos.
- 🔊 **Web Audio Integrado (`js/audio.js`)**: Síntese sonora e efeitos de áudio responsivos a cada interação.
- 📱 **QR Code Dinâmico (`js/qrcode.bundle.js`)**: Compartilhamento rápido para celulares dos visitantes do estande.
- 🎨 **Design Moderno & Mobile-First**: Interface futurista, dark mode com glassmorphism e microinterações fluidas.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** semântico
- **CSS3** avançado (Glassmorphism, CSS Grid, Flexbox, Animações e Variáveis CSS)
- **JavaScript (Vanilla ES6+)** modular
- **Web Audio API** para efeitos sonoros dinâmicos
- **Node.js / QRCode** para geração e manipulação de QR Codes
- **Vercel** para hospedagem e deploy contínuo

## 💻 Como Rodar Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/GuelBDev/ecotech-feira-2026.git
   cd ecotech-feira-2026
   ```

2. **Abra o arquivo principal:**
   - Execute o script `Iniciar_Site_da_Feira.bat` ou abra diretamente o arquivo `index.html` em seu navegador.
   - Ou utilize uma extensão como o *Live Server* do VS Code.
